# QSystem

Single repository for QSystem variants. Use branches to switch between versions.

## Branches

| Branch | Description |
|--------|-------------|
| **main** | Same content as `qsystem3` (current default). |
| **qsystem2** | Placeholder (original QSystem2 repo was empty). |
| **qsystem3** | Full QSystem3 project (queue system, admin, server, etc.). |

Clone and checkout the branch you need:

```bash
git clone https://github.com/KingEGame/QSystem.git
cd QSystem
git checkout qsystem3   # or main, or qsystem2
```

Previously these were separate repos (QSystem, QSystem2, QSystem3); they are now consolidated here.
